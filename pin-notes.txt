Q1 Remote-Start Circuit

Part: BSS138 (N-channel MOSFET, SOT-23, 50 V / 0.22 A, Vgs(th) 0.8-1.5 V)
Net:  /WP_SW  (Q1 drain <-> WittyPi J3 pin 5)

┌────────┬──────────────┬──────────────────────────────┐
│  Node  │  SOT-23 pad  │         Connects To          │
├────────┼──────────────┼──────────────────────────────┤
│ Gate   │ 1            │ R8 (100 Ω) from mDot PB_1;   │
│        │              │ R3 (10 kΩ) pulldown to GND   │
├────────┼──────────────┼──────────────────────────────┤
│ Source │ 2            │ GND                          │
├────────┼──────────────┼──────────────────────────────┤
│ Drain  │ 3            │ WittyPi J3 SW (pin 5)        │
└────────┴──────────────┴──────────────────────────────┘

⚠ Pad order is G-S-D (pads 1-2-3), the standard SOT-23 MOSFET pinout. Use a symbol
based on Q_NMOS_GSD (e.g. Transistor_FET:BSS138). Do NOT use Simulation_SPICE:NMOS -
its pins are numbered D=1, G=2, S=3, which silently mis-pins the part on the PCB.
The mDot drives the gate at 3.3 V, so the FET must be logic-level.
